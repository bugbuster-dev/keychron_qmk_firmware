# Q3 Max Integration into 2025q3 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Port the custom dynamic features (Combo, Tap Dance, Leader) and specific keymaps from `keychron_q3_max` into the `upstream/2025q3` baseline.

**Architecture:** Use an "Integration Porting" approach. Create a new branch from `upstream/2025q3`, then selectively port the custom C logic and update the keymaps to the new "Max" series standards (UG lighting system and `keychron/` folder structure).

**Tech Stack:** QMK Firmware, C, Git.

Copy content from `keychron_q3_max:keyboards/keychron/q3_max/combo_eeprom.h` to the new branch.

**Step 2: Port `combo_eeprom.c`**
Copy content from `keychron_q3_max:keyboards/keychron/q3_max/combo_eeprom.c` to the new branch.

## Phase 3: Keymap Migration

### Task 5: Migrate Keymap Structure and Commands

**Files:**
- Create: `keyboards/keychron/q3_max/keymaps/keychron/keymap.c`
- Modify: `keyboards/keychron/q3_max/ansi_encoder/keymaps/keychron/keymap.c` (and ISO equivalent)

**Step 1: Migrate folder structure**
Delete `keyboards/keychron/q3_max/ansi_encoder/keymaps/via` and create `keyboards/keychron/q3_max/ansi_encoder/keymaps/keychron`.

**Step 2: Update Lighting Commands**
In the keymap files, replace:
- `RGB_MOD` $\rightarrow$ `UG_NEXT`
- `RGB_VAD` $\rightarrow$ `UG_VALD`
- `RGB_VAI` $\rightarrow$ `UG_VALU`
- `RGB_TOG` $\rightarrow$ `UG_TOGG`
- `RGB_HUI` $\rightarrow$ `UG_HUEU`
- `RGB_HUD` $\rightarrow$ `UG_HUED`
- `RGB_SAI` $\rightarrow$ `UG_SATU`
- `RGB_SAD` $\rightarrow$ `UG_SATD`
- `RGB_SPI` $\rightarrow$ `UG_SPDU`
- `RGB_SPD` $\rightarrow$ `UG_SPDD`

**Step 3: Restore Custom Layouts**
Merge the custom `LAYOUT_tkl_ansi` definitions from `keychron_q3_max` into the new files, ensuring the `UG_` commands are used.

**Step 4: Commit**
```bash
git add keyboards/keychron/q3_max/ansi_encoder/keymaps/keychron/
git commit -m "feat: migrate keymaps to 2025q3 structure and UG commands"
```
